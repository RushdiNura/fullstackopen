# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save. The form's onsubmit handler calls e.preventDefault(), so the default form submission is prevented

    Note right of browser: The browser adds the new note to the local notes list and redraws the notes on the page

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of browser: Request body is JSON: { "content": "...", "date": "..." } with Content-Type: application/json
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: The server does not ask for a redirect. The browser stays on the same page and sends no further HTTP requests.
